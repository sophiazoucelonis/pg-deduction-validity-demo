# This is a customized (ejected) demo

This folder is a **frozen local copy** of the demo-prototype app, created so this
ONE demo could be customized beyond what the standard demo building blocks allow.

- **Edits here affect ONLY this demo.** Never edit the shared app at
  `plugin/skills/demo-prototype/app/` to customize a single demo — that bundle
  renders everyone's demos.
- **Frozen:** this copy does NOT receive future plugin/app updates. That's expected.
- **Local only:** this demo can't be turned into a shareable link; run it locally
  with `atlas-demo serve <owner> <slug>` (it serves on :8081).
- Created by `atlas-demo eject`. See `.atlas-eject.json` for provenance.
